# Population Descriptive & Predictive Analytics Web Application

An interactive and modular Streamlit web app designed to load your population dataset, run key descriptive statistics, compute advanced distribution plots, evaluate four distinct classification models, and offer real-time single evaluations.

## Project Directory Structure
Place all generated files into a single project directory:

```text
population_analytics/
├── app.py
├── data_processing.py
├── visualizations.py
├── model.py
├── evaluation.py
├── prediction.py
├── requirements.txt
└── README.md
```

## Running Locally
1. Ensure you have Python installed.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Launch the Streamlit application:
   ```bash
   streamlit run app.py
   ```
